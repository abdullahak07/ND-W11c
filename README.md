# COMP6013 Week 11 — IoT Security City

A Vercel-ready interactive teaching website for **Week 11: Internet of Things Security**.

## Design concept

A bright animated **smart-city defense lab** rather than a slide deck. Students move through the IoT ecosystem from the device itself to edge/fog/core/cloud, then defend it against architectural, physical and cryptographic threats.

## Interactive modules

- **Build a Thing** — activate sensor, actuator, microcontroller, transceiver and power
- **Where Should It Run?** — choose edge/fog/cloud processing from latency and scale scenarios
- **Smart Hospital Risk Triage** — identify the most immediate IoT security-development risks
- **Save the City** — map scenarios to NIST IoT security objectives
- **Tamper Lab** — test resistance, evidence and detection mechanisms on a physical enclosure
- **Trusted Gateway Handshake** — build identity, mutual authentication, data protection and maintainability in order
- **Replay Attack Simulator** — accept or reject MiniSec-U packet counters
- **MiniSec Mode Selector** — choose MiniSec-U or MiniSec-B
- **9-question final challenge** with immediate feedback and Defense XP

## Lecture coverage

- Scope and evolution of IoT
- Sensors, actuators, microcontrollers, transceivers and power
- RFID
- Edge, gateways, fog, core and cloud
- Cloud vs fog characteristics
- IoT security development issues
- NIST IoT security objectives
- Tamper resistance and tamper detection
- IoT security requirements
- Gateway security functions
- IoT security environment
- MiniSec, Skipjack and OCB
- MiniSec-U / MiniSec-B and replay protection

Each major section also includes **flip-in-place deep-dive cards** with additional lecture detail.
